Executive summary

Built end to end as a solo architect: design, deployment, failure analysis and hardening.

Edge telemetry ingestion is decoupled from AI inference through Amazon SQS, so intrusion bursts are absorbed asynchronously instead of exhausting upstream API quotas. Google Gemini 3.8 Flash performs Tier-2 triage and maps threats to MITRE ATT&CK. On a confirmed true positive, a Boto3 call injects a VPC Network ACL deny rule within seconds, guarded by state tracking so the same attacker never triggers duplicate rule changes.

Every component runs under least-privilege IAM Instance Profiles.

  • Ingestion and compute fully decoupled
  • AI triage mapped to MITRE ATT&CK
  • Idempotent automated containment
  • Dead-letter queue for poison-pill events
  • Retry matrix with exponential backoff

Queue upgrade: from direct invoke to an SQS buffer

Version one wired EventBridge straight into Lambda. A brute-force burst started many Lambdas at once, which hit the Gemini free-tier limits (HTTP 429) and dropped alerts. Inserting SQS between them fixed it. Try both versions below (illustrative replay).

Burst control

The queue holds the spike. Lambda drains it at a fixed concurrency of 2 instead of fanning out.

Quota safety

Outbound Gemini calls are metered, so the 5 requests-per-minute free tier is no longer blown by a storm.

Failure handling

Failed messages are retried, and poison-pill events move to a dead-letter queue instead of looping forever.

Delivery

Each confirmed incident ends with a Slack webhook briefing, so the response is visible without opening AWS.

Security design decisions

What keeps it safe to run with nobody watching.

No static AWS keys

The edge host uses an IAM Instance Profile (events:PutEvents only) and Lambda uses a scoped execution role. The only third-party secrets are the Gemini API key (triage) and the Slack webhook URL (alerts).

Least privilege

Lambda may change only the NACL rule it owns, read its queue and write its logs. Nothing broader.

Idempotent response

State tracking checks for an existing deny rule before creating one, which prevents duplicate calls and rule-table thrashing.

Failure isolation

SQS buffer, DLQ for poison pills and bounded concurrency keep one noisy source from taking down triage.

Signal over noise

The forwarder keeps only Level 7+ alerts, which cuts LLM calls.

Sanitised evidence

Adversary IPs are redacted from all documentation and demos.

Hardened host

No root account use, a dedicated IAM deployment user, RSA SSH key login, and inbound EC2 traffic limited to HTTPS (443).

Simplified excerpt: how the Lambda handler decides and acts
def lambda_handler(event, context):
    for rec in event["Records"]:
        alert = json.loads(rec["body"])["detail"]
        verdict = ask_gemini(alert)
        if verdict["classification"] != "TRUE_POSITIVE":
            continue
        ip = alert["data"]["srcip"]
        if already_blocked(ip):
            print(f"ALREADY BLOCKED {ip}, skipping")
            continue
        block_ip(ip)            # NACL inbound DENY, rule #50
        notify_chatops(alert, verdict)

def ask_gemini(alert, tries=4):
    for n in range(tries):
        try:
            with urllib.request.urlopen(build_req(alert), timeout=12) as r:
                return parse(r.read())
        except (urllib.error.HTTPError, TimeoutError):
            time.sleep(2 ** n)  # exponential backoff
    raise RuntimeError("gemini unavailable")  # message returns to SQS, then DLQ
